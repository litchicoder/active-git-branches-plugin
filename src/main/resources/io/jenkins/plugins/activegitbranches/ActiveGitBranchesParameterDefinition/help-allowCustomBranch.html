When enabled, the parameter dropdown will include an extra ✏ Custom (manual input)... option. Selecting it reveals a text field where the user can type any branch name, even if that branch is not in the active list (or is excluded by Branch Filter).

Use this when you want users to occasionally build branches that are outside the active set (e.g. an old release branch) without having to loosen the Branch Filter regex permanently.

Notes:

  • Manual input bypasses the Branch Filter regex.
  • The branch name is trimmed and rejected if it contains whitespace or any of ~ ^ : ? * [ \, starts with -, or contains .. (basic git ref-name hygiene).
  • Existence on the remote is not verified at submit time; if the branch does not exist, the build will fail at the SCM checkout step as usual.
  • Default: disabled. Recommended only for jobs whose builders trust the user to choose any branch.
